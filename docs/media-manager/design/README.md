## Running the prototype

```sh
node docs/media-manager/design/scripts/serve.mjs   # then open http://localhost:4321/prototype/
```

The server binds to `127.0.0.1` by default. To reach it from another device, for example when it runs on
a remote machine, add `--host 0.0.0.0` (and `--port <n>` if needed) and allow the port in your firewall.
It serves only the design folder, read-only. Useful URL parameters:

| Parameter | Effect |
|---|---|
| `theme=dark\|light` | Theme. Defaults to the system preference |
| `chrome=0` | Hides the dev box, for screenshots |
| `scenario=normal\|pro\|per-user\|no-filebird\|no-plugin\|author\|trash\|offline\|loading\|empty` | Simulated site situation (also in the dev box) |
| `folder`, `q`, `type`, `alt=missing`, `sort`, `layout`, `density`, `item` | App state, as the real app would keep it in the URL. `item=<id>` opens detail mode |

## Prototype structure

- `prototype/index.html`: the app shell.
- `prototype/system.html`: the living design-system reference (tokens and every component state).
- `prototype/css/`:
  - `tokens.css`: the design tokens (primitives plus semantic, dark and light);
  - `base.css`: reset and defaults;
  - `layout.css`: app shell and regions;
  - `components.css`: all components;
  - `system.css`: layout of the reference page.
- `prototype/js/`: plain ES modules, no build step, no dependencies.
  - `store.js`: the single state and the derived collection;
  - `url.js`: state ↔ query parameters;
  - `keymap.js`: every shortcut, plus a layout-safety self-check;
  - `grid.js`, `detail.js`, `inspector.js`, `folders.js`, `toolbar.js`: the views;
  - `transition.js`: the grid↔detail View Transition;
  - `features.js`: a hook for later feature modules.
- `prototype/data/`: the sample library, generated by `scripts/build-sample-data.mjs`.

## Screenshots and checks

Playwright is not a repo dependency. Install it anywhere (`npm install playwright && npx playwright install
chromium`) and point `NODE_PATH` at that `node_modules`:

```sh
NODE_PATH=/path/to/node_modules node docs/media-manager/design/scripts/screenshots.mjs [--only <text>] [--no-checks]
NODE_PATH=/path/to/node_modules node docs/media-manager/design/scripts/token-report.mjs   # contrast and neutrality table
```

The script serves the prototype, runs the interaction checks, and writes 1440 × 900 JPEGs to
`screenshots/`, one dark and one light per screen.

- **Core checks:** keyboard navigation, detail mode and Back, deep links, panel toggles, hover contrast
  of every control, peek, filters and zoom.
- **Area checks:** each feature area adds its own shots and checks in `scripts/shots/<area>.mjs`
  (`core`, `folders`, `inspector`, `system`).
- **Errors:** any error from the prototype fails the run.
