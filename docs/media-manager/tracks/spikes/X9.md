# Spike X9: FileBird Pro detection (track P1)

**Question:** can the plugin tell FileBird Pro from FileBird Lite without a licence (D15), well enough
to show folder colours (D23) only on Pro?

**Decision:** yes, with positive signals only. `filebird.pro` is true only when the active FileBird
says it is Pro. On Lite it is always false. The detection stays unverified against a live Pro site,
and a filter can override it.

## What was checked

- **Lite 6.5.9 (live, in the dev stack):**
  - `NJFB_PLUGIN_BASE_NAME` is `filebird/filebird.php`.
  - The header's `Plugin Name` is `FileBird Lite`.
  - `/info` reports `pro: false`, and `GET /folders` reports `mode.pro: false`, `colorsWritable: false`
    and `color: null` for every folder.
  - `PATCH /folders/{id}` with `color` answers 409 `wpu_pro_required` (contract test).
- **Lite's source:** no runtime licence or Pro flag exists. `Classes/ActivePro.php` only adds an Envato
  login URL and `license.status = false` to the admin UI data. The colour route (`update-folder-color`)
  and its model logic work server-side in Lite too, so their presence says nothing about Pro.
- **Public signals for Pro:**
  - Pro is distributed as its own plugin directory, `filebird-pro/` (a public `wp-content/plugins/filebird-pro/`
    listing with `filebird.php` and `changelog.txt`, and a support thread naming the folder).
  - Lite's `filebird.php` refuses to run beside another FileBird (`function_exists('FileBird\\init')`
    → `Fallback.php`), so only one FileBird is ever active.
  - The Pro source isn't public, so its header text and constants could not be read.

## What the plugin does (`FileBird\Adapter::is_pro()`)

1. FileBird must be active (`FileBird\Model\Folder` loaded).
2. Pro if `NJFB_PLUGIN_BASE_NAME` starts with `filebird-pro/`, **or** the header's `Plugin Name`
   contains the word "Pro" and not the word "Lite".
3. The result goes through the filter `wpu_filebird_pro`, so a site (or a test) can force it.

Lite is never detected as Pro: its directory is `filebird/` and its name says Lite. The failure mode
on a real Pro site is a false negative. Colours then stay hidden, which is the "hide Pro features in
v1" fallback that X9 allows.

Colour writes go through FileBird's own `FolderController::updateFolderColor()` (D17). The adapter
answers 501 `wpu_not_implemented` if a FileBird version lacks it.
